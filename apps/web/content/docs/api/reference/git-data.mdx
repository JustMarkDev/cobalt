### `git.blame`

`GET /repos/{owner}/{repo}/git/blame`

**Who last wrote each line of a file**

Per line, from the store's own blame (it follows the file across renames): the commit that last wrote it, its author and date. `from` and `to` pick a range of lines; at most 5000 come back and `has_more` says when more follow. To go from a line to the change and agent run behind it, use `repos.provenance`. With a full commit id as `ref` the answer never changes and is cacheable for good.

| About      |                                            |
| ---------- | ------------------------------------------ |
| Safety     | `read`, safe to repeat                     |
| Needs      | nothing for public data, a token otherwise |
| Scopes     | `repo:read`                                |
| Rate limit | `heavy` pool, 2 units                      |
| Success    | `200`, a `blame`                           |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Query parameters**

| Name   | Type                                       | Notes                                                 |
| ------ | ------------------------------------------ | ----------------------------------------------------- |
| `path` | string (up to 1000 characters, at least 1) | Required. A file, without a leading slash             |
| `ref`  | string (up to 200 characters)              | A branch, or a commit id. Default: the default branch |
| `from` | integer (min 1, max 9007199254740991)      | First line, 1-based. Default: 1                       |
| `to`   | integer (min 1, max 9007199254740991)      | Last line, inclusive. Default: the end of the file    |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`moved`](/docs/api/errors#moved), [`not_found`](/docs/api/errors#not_found), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unsupported_version`](/docs/api/errors#unsupported_version)

**Example**
