**Pipeline runs in a repository**

Newest first. Each is a workflow run; a check on a change is the result of one.

### `pipelines.start`

`POST /repos/{owner}/{repo}/pipelines`

**Start a workflow**

Queues a run of a workflow that has run before, on the newest commit of `branch` (the default branch if left out), for a runner to claim. Not idempotent by nature: send an `Idempotency-Key` to retry safely.

| About      |                                     |
| ---------- | ----------------------------------- |
| Safety     | `write`, not safe to repeat blindly |
| Needs      | a token                             |
| Scopes     | `repo:write`                        |
| Rate limit | `write` pool, 1 unit                |
| Dry run    | `?dry_run=true`                     |
| Success    | `201`, a `pipeline_run`             |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Query parameters**

| Name      | Type    | Notes                                                                                                   |
| --------- | ------- | ------------------------------------------------------------------------------------------------------- |
| `dry_run` | boolean | Run every check and change nothing. The answer is what would have been returned, with Sx-Dry-Run: true. |

**Request body**

| Member     | Type                                      | Notes     |
| ---------- | ----------------------------------------- | --------- |
| `workflow` | string (up to 100 characters, at least 1) | Required. |
| `branch`   | string (up to 200 characters, at least 1) |           |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`forbidden`](/docs/api/errors#forbidden), [`idempotency_key_reused`](/docs/api/errors#idempotency_key_reused), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`moved`](/docs/api/errors#moved), [`not_found`](/docs/api/errors#not_found), [`payload_too_large`](/docs/api/errors#payload_too_large), [`request_in_progress`](/docs/api/errors#request_in_progress), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unauthenticated`](/docs/api/errors#unauthenticated), [`unsupported_media_type`](/docs/api/errors#unsupported_media_type), [`unsupported_version`](/docs/api/errors#unsupported_version)

### `pipelines.rerun`

`POST /repos/{owner}/{repo}/pipelines/{run}/rerun`

**Run a workflow again**

A new run of the same workflow on the same commit, queued for a runner. Not idempotent by nature: send an `Idempotency-Key` to retry safely.

| About      |                                     |
| ---------- | ----------------------------------- |
| Safety     | `write`, not safe to repeat blindly |
| Needs      | a token                             |
| Scopes     | `repo:write`                        |
| Rate limit | `write` pool, 1 unit                |
| Dry run    | `?dry_run=true`                     |
| Success    | `201`, a `pipeline_run`             |

**Path parameters**

| Name    | Type                                  | Notes |
| ------- | ------------------------------------- | ----- |
| `owner` | string                                |       |
| `repo`  | string                                |       |
| `run`   | integer (min 1, max 9007199254740991) |       |

**Query parameters**

| Name      | Type    | Notes                                                                                                   |
| --------- | ------- | ------------------------------------------------------------------------------------------------------- |
| `dry_run` | boolean | Run every check and change nothing. The answer is what would have been returned, with Sx-Dry-Run: true. |

**Errors**

### `pipelines.claim`

`POST /repos/{owner}/{repo}/pipelines/claim`

**Take the next queued job, as a runner**

The oldest queued job in the repository, now running on `runner`. Answers `204` when nothing is waiting. The runner reads the workflow file at `sha`, runs the job's steps, and reports each one.

| About      |                                     |
| ---------- | ----------------------------------- |
| Safety     | `write`, not safe to repeat blindly |
| Needs      | a token                             |
| Scopes     | `repo:write`                        |
| Rate limit | `write` pool, 1 unit                |
| Success    | `200`, a `pipeline_job`             |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Request body**

| Member   | Type                                      | Notes                                         |
| -------- | ----------------------------------------- | --------------------------------------------- |
| `runner` | string (up to 100 characters, at least 1) | Required. The runner's name, shown on the job |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`forbidden`](/docs/api/errors#forbidden), [`idempotency_key_reused`](/docs/api/errors#idempotency_key_reused), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`moved`](/docs/api/errors#moved), [`not_found`](/docs/api/errors#not_found), [`payload_too_large`](/docs/api/errors#payload_too_large), [`request_in_progress`](/docs/api/errors#request_in_progress), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unauthenticated`](/docs/api/errors#unauthenticated), [`unsupported_media_type`](/docs/api/errors#unsupported_media_type), [`unsupported_version`](/docs/api/errors#unsupported_version)

**Example**
