### `handoffs.start`

`POST /repos/{owner}/{repo}/handoffs`

**Hand an issue, a change or a failed run to your agent**

What the Hand off button does: queues a job for your own agent, a runner labelled `t3` (`cb runner register <name> --labels t3`, then `cb runner start`), which opens a T3 Code thread on its machine with the prompt built from the issue or change. Nothing to copy or run by hand. `agent` says whether such a runner exists; without one the job waits for it. The same subject on the same commit is queued once.

| About      |                         |
| ---------- | ----------------------- |
| Safety     | `write`, safe to repeat |
| Needs      | a token                 |
| Scopes     | `repo:write`            |
| Rate limit | `write` pool, 1 unit    |
| Success    | `202`, a `handoff`      |

**Path parameters**

| Name    | Type   | Notes |
| ------- | ------ | ----- |
| `owner` | string |       |
| `repo`  | string |       |

**Request body**

| Member    | Type             | Notes                                                            |
| --------- | ---------------- | ---------------------------------------------------------------- |
| `subject` | string (pattern) | Required. An issue or change number, or run:N for a pipeline run |

### `pipelines.report`

Send `running` when it starts, then `success`, `failure` or `skipped`, with the log lines it wrote (5,000 kept a step). A failure skips the rest of the job. When every step of a job is done the job is, and when every job is done the run is.

| About      |                                     |
| ---------- | ----------------------------------- |
| Safety     | `write`, not safe to repeat blindly |

| Scopes     | `repo:write`                        |
| Rate limit | `write` pool, 1 unit                |
| Success    | `200`, a `pipeline_run`             |

**Path parameters**

| Name    | Type                                  | Notes |
| ------- | ------------------------------------- | ----- |
| `owner` | string                                |       |
| `repo`  | string                                |       |
| `run`   | integer (min 1, max 9007199254740991) |       |
| `job`   | integer (min 1, max 9007199254740991) |       |
| `step`  | integer (min 1, max 9007199254740991) |       |

**Request body**

| Member        | Type                                             | Notes     |
| ------------- | ------------------------------------------------ | --------- |
| `status`      | `running` or `success` or `failure` or `skipped` | Required. |

### `runners.wait`

`POST /runners/wait`

**Pause a step of a job it holds, as the runner**

A step that waits on a person, an approval or an outside agent, paused by the runner running it, with the runner token. The job keeps the runner and is never claimed again; whom it waits on is told; if nobody resumes it by `expires_at` (7 days by default, 30 at most) the step and the run fail. Resuming takes a login with `repo:write` (`pipelines.resume`): a runner's token cannot answer its own wait.

| About      |                         |
| ---------- | ----------------------- |
| Safety     | `write`, safe to repeat |
| Needs      | a token                 |
| Scopes     | `runners:report`        |
| Rate limit | `write` pool, 1 unit    |
| Success    | `200`, a `pipeline_run` |

**Request body**

| Member       | Type                                              | Notes     |
| ------------ | ------------------------------------------------- | --------- |
| `repo`       | string (pattern)                                  | Required. |
| `run`        | integer (min 1, max 9007199254740991)             | Required. |
| `job`        | integer (min 1, max 9007199254740991)             | Required. |
| `step`       | integer (min 1, max 9007199254740991)             | Required. |
| `kind`       | `person` or `agent` or `approval`                 | Required. |
| `reason`     | string (up to 500 characters, at least 1)         | Required. |
| `target`     | string (up to 100 characters, at least 1) or null |           |
| `expires_at` | string (date-time, pattern)                       |           |

**Errors**

[`backend_unavailable`](/docs/api/errors#backend_unavailable), [`concurrency_limited`](/docs/api/errors#concurrency_limited), [`forbidden`](/docs/api/errors#forbidden), [`idempotency_key_reused`](/docs/api/errors#idempotency_key_reused), [`insufficient_scope`](/docs/api/errors#insufficient_scope), [`invalid_request`](/docs/api/errors#invalid_request), [`invalid_state`](/docs/api/errors#invalid_state), [`not_found`](/docs/api/errors#not_found), [`payload_too_large`](/docs/api/errors#payload_too_large), [`request_in_progress`](/docs/api/errors#request_in_progress), [`token_expired`](/docs/api/errors#token_expired), [`token_invalid`](/docs/api/errors#token_invalid), [`token_revoked`](/docs/api/errors#token_revoked), [`unauthenticated`](/docs/api/errors#unauthenticated), [`unsupported_media_type`](/docs/api/errors#unsupported_media_type), [`unsupported_version`](/docs/api/errors#unsupported_version)
