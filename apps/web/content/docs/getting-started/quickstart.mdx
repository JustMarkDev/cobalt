## 1. Install cb

```bash
bun add -g @cobaltforge/cli
cb --version
```

See [Install](/docs/cli/install) for other ways.

## 2. Create a repository

```bash
cb repo create dana/notes --public
git clone https://cobaltforge.dev/dana/notes.git
cd notes
```

Git asks for a username and a password. Use any username, and a token with the `repo:read` and `repo:write` scopes as the password (Settings, Agents and tokens). The token is checked here: your Git client never receives a credential for the git store behind it.

Running `cb repo create` twice is safe. The second call returns the repository that exists.

## 3. Push a branch and open a change

```bash
git switch -c fix-typos
git commit -am "Fix typos in the readme"
git push -u origin fix-typos
cb change create
```

`cb change create` asks nothing. The title is your last commit, the base is your default branch, and the branch is the one you are on. Run it again after another push and it adds a **patch set** to the same change.

## 4. See what stops it landing

```bash
cb change view
```

```text
#3  open  Fix typos in the readme
patch sets 1, 0 approval, ci pending
  blocked: ci/test is running
  blocked: needs 1 human approval
```

## 5. Land it

```bash
cb change land
```

If a policy blocks it, `cb` exits with code `5` and says which requirement is missing. See [Policies](/docs/concepts/policies).
