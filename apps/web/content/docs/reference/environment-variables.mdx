title: Environment variables
description: Variables cb reads.
---

| Variable                            | Meaning                                                                   |
| ----------------------------------- | ------------------------------------------------------------------------- |
| `CB_TOKEN`                          | Token used to sign in                                                     |
| `CB_HOST`                           | Server address. Same as the `host` setting                                |
| `CB_REPO`                           | Repository to use when you are not in a clone                             |
| `CB_ACCOUNT`                        | Account to act as. Same as the `account` setting, and beats the saved one |
| `CB_CONFIG_DIR`                     | Folder that holds `config.json`                                           |
| `CB_OUTPUT`                         | `auto`, `json` or `text`                                                  |
| `CB_HANDOFF_TO`                     | Default for `cb handoff`: `t3` or `boat`                                  |
| `CB_TOOL`, `CB_MODEL`               | The tool and model `cb` declares on every request, for receipts           |
| `CB_CHANGE_BASE`, `CB_CHANGE_DRAFT` | Defaults for `cb change create`                                           |
| `CB_CLONE_PROTOCOL`                 | `ssh` or `https`                                                          |
| `CB_DEBUG`                          | Print stack traces                                                        |
| `NO_COLOR`                          | Turn off colour                                                           |

Every setting can be set as `CB_` plus its key in capitals, with `.` written as `_`. See [Settings](/docs/cli/config).
