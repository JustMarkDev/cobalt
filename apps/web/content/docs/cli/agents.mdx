## Sign the machine in once

```bash
cb auth login
```

Every agent on the machine uses this login. Set `CB_MODEL` (and `CB_TOOL`, if the orchestrator does not) in the environment the agent runs `cb` in, so each write keeps the model on its receipt.

## Hand off

```bash
cb handoff 216            # to T3 Code, on this machine
cb handoff 4 --to boat    # to boat.dev, in the cloud
```

It builds the prompt from the issue or change (names and structure, never a secret value) and prints the command that hands it to the orchestrator. cobalt starts no agent itself. Set the default with `cb config set handoff.to boat`.

The MCP server has the same as `hand_off`.

## Teach an agent cb

```bash
cb skill install                   # .claude/skills/cb/SKILL.md
cb skill install --target agents   # a block in AGENTS.md
```
