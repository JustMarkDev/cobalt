## Sign the machine in once

```bash
sx auth login
```

Every agent on the machine uses this login. Set `SX_MODEL` (and `SX_TOOL`, if the orchestrator does not) in the environment the agent runs `sx` in, so each write keeps the model on its receipt.

## Hand off

```bash
sx handoff 216            # to T3 Code, on this machine
sx handoff 4 --to boat    # to boat.dev, in the cloud
```

It builds the prompt from the issue or change (names and structure, never a secret value) and prints the command that hands it to the orchestrator. source.code starts no agent itself. Set the default with `sx config set handoff.to boat`.

The MCP server has the same as `hand_off`.

## Teach an agent sx

```bash
sx skill install                   # .claude/skills/sx/SKILL.md
sx skill install --target agents   # a block in AGENTS.md
```
