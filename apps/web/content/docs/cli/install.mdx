`cb` is a single TypeScript program that runs on [Bun](https://bun.sh).

```bash
bun add -g @cobaltforge/cli
cb --version
```

From a checkout of the cobalt repository you can run it directly:

```bash
bun packages/cli/src/main.ts --help
```

## Shell completion

```bash
cb completion zsh  > "${fpath[1]}/_cb"
cb completion bash > /etc/bash_completion.d/cb
cb completion fish > ~/.config/fish/completions/cb.fish
```

## Updating

Update it the way you installed it, for example `bun update -g @cobaltforge/cli`. Settings in `~/.config/cb/config.json` are kept.
